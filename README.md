# Colorful-Memory-Match-Game

## About The Project

A vibrant, fully responsive **Memory Match Game** built with vanilla HTML5, CSS3, and JavaScript. 

Players flip cards to discover matching pairs of dynamic, vivid colors. The game exercises visual retention and speed while tracking player performance dynamically.

### Key Features
* **Dynamic Color Generation:** Features an 8-colour palette shuffled differently every game session.
* **Pure Vanilla Stack:** Zero external frameworks, dependencies, or libraries.
* **Fisher-Yates Shuffle:** Uses a randomized mathematical shuffle algorithm for unique setups.
* **CSS 3D Transforms:** Smooth, high-performance card flipping animation engine.
* **Live Score Tracker:** Real-time movement counters to calculate overall score efficiency.
